# M0 — Repository Bootstrap

- **Date:** 2026-08-12
- **Status:** Complete — reconciled against the spec documents (see the reconciliation addendum
  at the end of this worklog)

## Important caveat

The three governing specification documents (AI Build Implementation Playbook v2, Product &
Architecture Blueprint v2, AI-Powered ABSN Study System) were **not available** during M0: the
project docs location was empty and the GitHub repository had no commits. M0 was executed from the
founder's written M0 requirements instead. See ADR-0004 for the mandatory reconciliation step
before M1.

## Scope delivered

- npm-workspaces monorepo: `apps/app` (Expo app), `packages/config` (platform-agnostic domain
  logic), `docs/`, `.github/workflows/`.
- Expo SDK 57 / React Native 0.86 / React 19.2 / TypeScript app targeting iOS, Android, and web
  (Metro bundler, static web output). Single codebase; responsive layout pattern demonstrated on
  the home screen (narrow vs. ≥768 px wide layouts).
- `@avidia/config`: schema-validated client environment configuration (Zod) with unit tests. This
  package is where provider-independent domain logic (mastery, spaced repetition, simulations)
  will live in later milestones.
- Tooling: TypeScript strict mode everywhere, ESLint 9 (flat config, typescript-eslint, react,
  react-hooks), Prettier, Jest (jest-expo preset in the app; babel-jest in core).
- Environment hygiene: `.env.example` documenting all variables and secrecy rules; `.env*`
  git-ignored; startup-time validation that fails fast with readable errors.
- CI (GitHub Actions): format check → lint → typecheck → tests → production web export on every
  push/PR.
- Documentation: README, ADR-0001…0004, this worklog.

## Explicitly out of scope (deferred to later milestones)

Supabase, authentication, AI gateway/integration, billing, course uploads, RAG, mastery tracking,
spaced repetition, simulations, navigation library, backend services.

## Known limitations

- iOS/Android verified structurally (valid Expo config, bundle identifiers, Metro monorepo
  resolution) but not launched on a simulator/device in this environment.
- No navigation library yet (expo-router planned when the app gains a second screen); web export
  therefore uses SPA output rather than static multi-page output.
- `packages/config` is consumed as TypeScript source; a compile step will be added when a non-Metro
  consumer (backend) appears.

## Reconciliation addendum (2026-08-12)

The three governing documents arrived later the same day and a full reconciliation audit was
performed against them (authority order: Playbook v2 → Blueprint v2 → Study System). Outcome:
**pass with minor corrections** — no conflicts with M0's substance; all differences were naming
and tooling details prescribed by Playbook §4–§5 that M0 could not have known.

Corrections applied (details and rationale in ADR-0005):

1. Migrated npm workspaces → **pnpm workspaces + Turborepo** (`pnpm-workspace.yaml`, `turbo.json`,
   `.npmrc` with `node-linker=hoisted`), per the Playbook's repository contract.
2. Renamed `apps/student` → `apps/app` and `packages/core` → `packages/config` (`@avidia/app`,
   `@avidia/config`) to match the Playbook layout.
3. Aligned client env variables with Playbook §5: `EXPO_PUBLIC_API_BASE_URL`,
   `EXPO_PUBLIC_WEB_APP_URL`, `EXPO_PUBLIC_ANALYTICS_KEY` (schema, tests, `.env.example` updated).
4. Added the Playbook docs tree (`docs/product`, `docs/api`, `docs/prompts`, `docs/runbooks`) and
   stored the three source documents in `docs/product/`.
5. Added a CI secret-scanning job (gitleaks), per Playbook §26.
6. Updated ADR-0002 (superseded in part), closed ADR-0004, added ADR-0005.

Deliberately **not** created (intentional deferment, to avoid structurally misleading placeholder
packages): `packages/domain`, `packages/adaptive-engine`, `packages/ai-gateway`,
`packages/content`, `packages/retrieval`, `packages/ui`, `packages/telemetry`, `services/worker`,
`supabase/`. Each appears at the milestone that gives it real content.

Validation was re-run in full under pnpm + Turborepo after the changes; results in ADR-0005 and
the reconciliation report delivered to the founder.
